# s3x 标准

**crate**：`s3x` v0.1.1 · 依赖：`reqwest`、`tokio`、`hmac`/`sha2`/`hex`、`percent-encoding`、`quick-xml`、`bytes`、`thiserror`、`tracing`

## 1. 定位

s3x 提供 AWS S3 及 S3 兼容对象存储（MinIO / Ceph 等）的异步访问原语：手写 SigV4 签名、
virtual-hosted / path-style 双寻址、对象读写、预签名 URL、并发背压与重试。零内部耦合，
不含任何领域模型或业务编排，不依赖 aws-sdk。

## 2. 字段治理 / 数据约定

- `ObjectKey` 是唯一合法的对象键入口：非空、无前导 `/`、无 `..`、无控制字符、
  ≤ `MAX_OBJECT_KEY_BYTES`（1024）；数据面方法只接受 `ObjectKey`。
- SigV4 统一走 `sign_request` 及 `canonical_*` 纯函数原语，遵守 S3 的
  「规范化 URI 不做二次编码」规则、查询串排序与百分号编码、头值折叠、同名头合并；
  任何签名改动必须通过 AWS 官方 `aws-sig-v4-test-suite` 已知向量测试。
- XML 解析（ListObjectsV2 / DeleteObjects / 错误响应）统一走 `xml` 模块，
  禁止在 client 内散落手工解析。
- 环境变量前缀 `FOUNDATIONX_S3X_`，使用 `ENV_*` 常量而非硬编码字符串。

## 3. 资源治理

- `max_in_flight` 以 `tokio::sync::Semaphore` 背压，clamp 到 `HARD_MAX_IN_FLIGHT`；
  连接 / 请求超时 clamp 到 `HARD_MAX_CONNECT_TIMEOUT_MS` / `HARD_MAX_REQUEST_TIMEOUT_MS`。
- 重试指数退避 + 抖动（`RetryConfig`），上限 `HARD_MAX_RETRIES` / `MAX_RETRY_ATTEMPTS`；
  `S3Error::is_retryable` 区分瞬时故障（网络 / 超时 / 5xx / 429）与永久故障（4xx 鉴权、参数）。
- 错误响应体截断：服务端消息 ≤ `MAX_ERROR_MESSAGE_CHARS`（512），响应前缀
  ≤ `MAX_ERROR_BODY_BYTES`（4 KiB）；`list_objects_v2` 单页 ≤ `MAX_LIST_KEYS`（1000）。
- 预签名有效期自动收敛到 1 秒 ~ 7 天（`HARD_MAX_PRESIGN_EXPIRES_SECS` = 604800）。

## 4. 安全约定

- `access_key_secret` 与 `session_token` 只能经环境变量或 `S3ConfigBuilder` 注入，
  `from_toml` 会拒绝这两个键；二者永不进入错误消息、`Debug` 输出或 URL。
- 默认 TLS 校验开启（rustls）；明文 HTTP 上的 `UNSIGNED-PAYLOAD` 必须经
  `ENV_ALLOW_UNSIGNED_PAYLOAD_OVER_HTTP` 显式开启。
- 鉴权 / 权限失败立即返回，不重试。

## 5. 验收

```text
cargo fmt --all --check
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo package --no-verify
```

热路径基准（离线）：

```text
cargo bench --bench hot_path -- --quick
```

测试至少覆盖：SigV4 官方已知向量、canonical URI / 查询串编码边界、双寻址 URL 构造、
预签名有效期收敛、`ObjectKey` 非法输入拒绝、配置校验与 clamp、重试分类、
凭据脱敏（toml 拒绝 secret 键、Debug 不回显）、公开类型 `Send`/`Sync`/`Clone` 断言。

本 crate **必须同时具备**下列测试层（缺一层即验收失败）：

| 层 | 入口 | 说明 |
| --- | --- | --- |
| TDD | `tests/tdd_contracts.rs` | 公开入口变异探测（TDD-PROBE） |
| SDD | `tests/sdd_spec.rs` | `docs/标准.md` 章节对照（SPEC-MAP） |
| 单元测试 | `src/**` 模块测试 + `tests/object_key.rs` / `tests/sigv4_vectors.rs` / `tests/pure_functions.rs` | 无网络、纯函数与类型边界 |
| 集成测试 | `tests/http_*.rs` / `tests/config_env.rs` / `tests/backpressure.rs` | 本地 HTTP 桩与配置/背压 |
| 基准测试 | `benches/hot_path.rs` | 离线热路径；见上 `cargo bench` |
| E2E | `tests/e2e_s3.rs`（离线公开面）与 `tests/live_s3.rs`（真 AWS，`#[ignore]`） | 离线 E2E 默认必跑；真连服须注入 `FOUNDATIONX_S3X_*`，不得把 NotRun 写成 PASS |

## 6. 质量门禁约束

- crate 级 `#![forbid(unsafe_code)]`、`#![deny(missing_docs)]` 不得移除。
- 公共 API 面由 lib.rs 的 `public_api_surface` 测试逐一点名；新增/删除导出必须同步该测试、
  `docs/API.md` 与本文件；breaking 变更走 SemVer major + CHANGELOG。
